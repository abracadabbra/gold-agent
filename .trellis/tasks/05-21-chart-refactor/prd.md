# 行情图重构

## Goal

重构行情图卡，支持多数据源/周期切换、K 线图、均线叠加、价差对比、指标联动子图。

## 范围

仅修改 `PriceChartCard` 组件及其内部子组件，不影响其他卡片。

## Requirements

- 数据源切换: intl / GLD / SHFE
- 时间周期: 1mo / 3mo / 6mo / 1y / 5y
- K 线图代替折线图
- MA20/MA50/MA200 叠加
- 国际 vs 国内价差对比图
- RSI/MACD/布林带作为子图嵌入主图下方

## Acceptance Criteria

- [ ] 三种数据源可切换，图表数据对应刷新
- [ ] 五种时间周期可切换
- [ ] K 线图正确显示 OHLC，红涨绿跌
- [ ] 均线正确叠加
- [ ] 价差模式正确计算并显示
- [ ] 四个指标子图（价差/RSI/MACD/BB）可切换
- [ ] 十字准星、日期标注简化显示
- [ ] Lint / typecheck 通过
